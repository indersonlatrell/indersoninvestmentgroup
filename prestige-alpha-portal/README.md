# Prestige Alpha Client Portal

Pages:
- `index.html` entry point
- `login.html` secure-login interface
- `dashboard.html` account overview
- `analytics.html` performance analytics
- `trades.html` trade ledger

Upload all files to the same published folder. For Render Static Sites, set the publish directory to this folder.

Important: the current login is a front-end demonstration using `sessionStorage`; it is not secure authentication. Production use requires a server-side identity provider, protected APIs, authorization checks, secure cookies, and real account data.
